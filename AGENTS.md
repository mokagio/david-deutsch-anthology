# David Deutsch Anthology

A static site generated from `list.yml` and deployed to GitHub Pages on push to `main`.

## Commands

```sh
rake                # test, generate, validate
rake test
rake generate       # public/index.html and public/podcast.rss
rake validate       # the feed works in a podcast client
rake count          # entry tallies
```

No Gemfile — Ruby stdlib only, version pinned in `.ruby-version`.

## Conventions

- Content goes in `list.yml`, markup in `templates/`, shared code in `lib/`.
- `public/` is generated and gitignored: never edit or commit it.
- `list.yml` uses YAML anchors and comments. Edit it as text; a round-trip through Ruby's YAML dumper renames every anchor and drops every comment.
- An entry reaches the feed only if its `audio` block records `url`, `type` and `length`, and only from `podcast_interviews` or `talks` (`FeedBuilder::LABELS`). The `/audit-list` skill finds and records all three; the size and type are there so the build never probes a third-party host, which is how a deploy once silently lost four episodes.
- `audio.duration` is the runtime a client shows beside an episode, optional and recorded in seconds. Without one the client displays 0s until it has downloaded the file. Seconds rather than a clock face because YAML 1.1 reads an unquoted `62:03` as 223380; `Duration` converts between the two, and only a feed or Apple ever states one.
- An item's description is generated by `ShowNotes` from what the entry records: what the recording is, where it was published, and whose it remains. The show's own blurb is never copied — this feed did not make the recording and has no account of it to give.
- `published_date` is the day the anthology asserts, and the feed stamps it midday UTC — midnight would be the recorded day only east of Greenwich, showing a New York listener the day before. `published_at` is optional and refines it to the instant the show's own feed stated, recorded by `/audit-list` in RFC 2822 and only when it falls on that same day. RFC 2822 rather than ISO 8601 because YAML types a bare `2026-02-12T09:30:00Z` as a `Time`, and the safe loaders refuse the class.
- `image_url` is the picture a client shows for an episode, read from the entry or from its `show`, and optional: without one a client falls back to the channel artwork, which is `assets/cover.{jpg,jpeg,png}` if that file exists. `/audit-list` records it, preferring the episode's own picture over the show's and measuring every candidate, because `og:image` is as often a banner crop as it is a cover.
- A title is the conversation's name without the show's numbering: `#4 - Decisions` is recorded as `Decisions`, because a position in one show's series says nothing among ninety entries sorted by date. `EpisodeTitle` strips the marked forms, `/add-entry` applies it, and `ListTest` fails the build on one that got in another way.
- An `other` entry's `name` may be written with Markdown emphasis, marked up by `Markdown` and rendered inside the entry's own link, so a title reads as a title and the line still behaves like every other link on the page.
  Emphasis and strength only: the name is already an anchor's text, so a link written in one stays the literal text it was typed as.
- `/add-entry` adds an interview from a URL; `/find-entries` looks for the ones the list is missing.
- Before touching podcast hosts or audio URLs, read [`docs/audio-sourcing.md`](docs/audio-sourcing.md) — what each host actually does, as against what it claims. Append to it whenever one surprises you.
